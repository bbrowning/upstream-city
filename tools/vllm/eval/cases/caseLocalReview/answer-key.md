# Answer key — immutable local-change review case

The local artifact must use exactly the same `change-review` lens as a PR. Load
`base.md` and `openai-frontend.md`, not `parser.md`. Request changes: the parallel
Responses request class drifts, the bare error lacks the framework's structured field
attribution, and the helper-only test does not drive the production serving path. The
verdict must record which reflexes materially informed those findings.
